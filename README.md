# German keyboard, English layout

Projection sheets for TOEFL test rooms with German keyboards: what each key types when the software switches to the English (US) layout.

- `English-Keyboard-Quick-Lookup.pdf`: one 16:9 page, US keyboard beside a "which German key do I press" list
- `German-Keyboard-English-Layout.pdf`: three A4 landscape pages (US keyboard, German keyboard in English mode, lookup list)
- `keyboard-map.html`: page source for the sheets
